spine-layout examples

One scene per Pixi major, each built with that major's engine.

  • Pixi 8: spine-pixi-v8 4.3 and a lazy 4.2, the 4.3 popup layout and a 4.2 settings button in one scene.
  • Pixi 7: @pixi-spine 4.0 runtime-3.8 and spine-pixi-v7 4.3, the 3.8 layout and the 4.3 popup layout on one engine.
  • Pixi 6: @pixi-spine 3.1 runtime-3.8, the 3.8 layout.
  • Pixi 5: pixi-spine 2.1, the 3.8 layout.
  • Pixi 4: pixi-spine 1.6, the 3.8 layout; a 3.7 export on pixi-spine 1.5.
