`@pixijs-userland/spine-layout/assetpack` packs a raw Spine export — the folder Spine View opens, skeleton JSON beside loose images — into one Spine atlas per skeleton at build time, as a pair of AssetPack pipes. `examples/assetpack` is a Vite project set up with it, and the Packing atlases guide covers the folder rules, options and loading.
