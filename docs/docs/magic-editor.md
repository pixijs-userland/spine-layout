title: Magic Editor
---

[magic-editor.com](https://magic-editor.com) is [Spine View](./spine-view.md) with the tools a
team needs around it. It is the same viewer on the same library, and opens without an account.
The extra tools ask you to sign in.

**Open it: [magic-editor.com](https://magic-editor.com)**

## What it adds

| Tool             | What it does                                                                           |
| ---------------- | -------------------------------------------------------------------------------------- |
| Bitmap fonts     | Builds a bitmap font for the `text_` slots from one PNG per character                  |
| GitHub sync      | Pulls, commits and pushes the project folder to a repository, straight from the editor |
| Draw-call report | Which slots open draw calls, why, and the peak of every animation, spine by spine      |

Everything on the [Spine View](./spine-view.md) page works the same here: opening a folder,
playing states and events, skins, texts, particles, sequences, the examples.

## Which one to use

|                                          | [Spine View](https://spineview.dev) | [Magic Editor](https://magic-editor.com) |
| ---------------------------------------- | ----------------------------------- | ---------------------------------------- |
| View and play a layout                   | Yes                                 | Yes                                      |
| Edit texts and particles, save sequences | Yes                                 | Yes                                      |
| Bitmap fonts                             | No                                  | After sign-in                            |
| GitHub sync                              | No                                  | After sign-in                            |
| Draw calls per frame                     | Yes                                 | Yes                                      |
| Draw-call report per spine               | No                                  | After sign-in                            |
| Account                                  | None                                | Optional                                 |
